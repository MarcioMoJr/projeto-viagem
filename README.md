## 📖 Sobre o projeto

O **Projeto Viagem** é um site sobre destinos de viagem, feito como o primeiro projeto da disciplina de PW1. Na página inicial, o visitante clica em um dos países da lista e acessa uma página com mais informações sobre ele.

|---|------|--------|

| 2 | 🇮🇹 **Itália** | [italia.html](https://marciomojr.github.io/projeto-viagem/paginas/italia.html) |
| 3 | 🇪🇬 **Egito** | [egito.html](https://marciomojr.github.io/projeto-viagem/paginas/egito.html) |

## 🛠️ Tecnologias

- **HTML5** – estrutura das páginas
- **CSS3** – estilização e layout
- **GitHub Pages** e **Vercel** – publicação do site

## 📁 Estrutura do projeto

```
projeto-viagem/
├── css/            # Folhas de estilo
├── img/            # Imagens
├── paginas/        # Uma página para cada país
└── index.html      # Página inicial
```

## 🚀 Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/MarcioMoJr/projeto-viagem.git
```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Ou, se preferir, acesse direto pelo site: [Projeto Viagem](https://projeto-viagem-two.vercel.app/)
